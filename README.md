## 使用

1. 下载仓库 ZIP 并完整解压，安装 Windows 64 位 Python 3.12。
2. 首次运行 `install.cmd` 安装依赖，然后运行 `start.cmd`。
3. 首次选择本机 `DNF.exe`，填写完整的小号（本机角色）和大号（另一台电脑的目标角色）名字。
4. 主界面可以随时修改两个名字，点击 **保存并切换（暂停）**。也可点击 **交换大小号**，交换并保存。
5. 游戏中切到对应本机角色，与目标组队进同一个副本房间，再按 **F8** 开始；F8 暂停，F9 停止。

不需要重启工具或手改 JSON。名字不允许为空或相同。切换会暂停移动，关闭旧坐标连接并丢弃旧名字识别缓存；完成后按 F8 才恢复。交换名字不会自动切换游戏中的登录角色。

## 旧版升级

关闭旧跟随工具，覆盖更新程序文件，保留本机配置。第一次读取旧 `coordinate-session.json` 的路径和名字；以后保存到独立的 `follow-session.json`，不会修改刷图助手的旧配置。重新选择客户端路径可运行 `configure.cmd`。

本包只跟随，不攻击、不使用药品、不处理装备。使用只读坐标和普通方向键，没有内存写入或注入。客户端 SHA256 必须匹配已适配版本。按完整名字、玩家对象类别、本机角色根、同房对象列表和坐标镜像核对，不再把职业类型固定到旧角色；找不到指定名字时等待重新识别，视觉备用也仅使用新的完整名字。

手动方向键松开后接回；Enter/Escape 暂停。不要与刷图助手同时运行，以免热键和输入冲突。不同客户端版本仍需另行适配，不保证任意服务器通用。
