## 自动跟随（另一台电脑安装包）

默认：本机 **上头召唤师** 跟随笔记本 **上头狂战**。

## 下载与使用

1. GitHub 页面点绿色 **Code → Download ZIP**，完整解压到普通文件夹。
2. 安装 Windows 64 位 Python 3.12（https://www.python.org/downloads/windows/）。已有 Python 3.11/3.12 可直接下一步。
3. 双击 `install.cmd`。它只在当前文件夹创建 `.venv` 并安装列出的依赖；首次需要联网。
4. 双击 `start.cmd`，首次选择这台电脑游戏目录里的 `DNF.exe`，检查人物名后保存。
5. 两人组队进入副本。把本机游戏放到前台，按 **F8** 开始/暂停，**F9** 停止。

按住方向键时让给手动操作，松开后接回。Enter/Escape 会暂停，关闭聊天或菜单后按 F8 恢复。
重新设置本机路径/名字可双击 `configure.cmd`。只改名字不会改变角色类型：换职业/角色外观应重新核对，不能冒充通用配置。

## 内容与范围

- 根目录入口是自动跟随；自动打怪、技能、装备维护等在独立的 `farming/` 目录。
- 使用已验证客户端的只读坐标，模拟正常方向键移动；没有游戏内存写入和注入。
- 已在笔记本验证坐标跟随、过房间、重启游戏重连、手动操作后恢复。**另一台电脑仍需首次实测。**
- 客户端文件 SHA256 必须匹配已验证版本，路径在本机配置；不同版本不会强行读旧结构。
- 这对角色使用坐标优先、名字识别补充。未打包针对旧角色训练的 YOLO 身体模型；不需要手动下载 `.onnx`。
- 看不到可靠角色或过图时暂时松开方向键等待。请先用一局验证跟随及过门。
- 热键被占用时关闭其他版本跟随工具，避免两个工具同时控制人物。

## 给另一台 Codex

先运行安装和离线自检，再配置本机 DNF.exe。本机跟随者上头召唤师，带队者上头狂战；不要反过来。
本客户端曾观测跟随者类型 0x016FC11C，带队者类型 0x016F972C；首次实机验证姓名与坐标，不要把旧进程地址当成永久地址。
不要上传 `coordinate-session.json`、日志、截图或内存研究数据。自动清怪源码与中文解析已放入 `farming/`，入口与跟随工具分开。

离线自检：`.venv\Scripts\python.exe -m unittest test_follow test_yolo test_name_rescue test_dungeon_telemetry test_coordinate_connection test_portable_follow`
安装包不包含私人截图，三个需要截图的回归测试会明确显示 skipped；其他测试照常运行。本机完整截图回归已验证。
