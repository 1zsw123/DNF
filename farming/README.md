# DNF 70 刷图助手

当前适配的是特定 70 客户端及狂战士技能栏。主流程使用只读坐标清怪、A* 绕障和键盘输入，OCR 负责菜单、血量和库存。不是通用 YOLO 自动打怪程序。

源码解析见 [ARCHITECTURE.md](ARCHITECTURE.md)。仓库根目录是另一台电脑使用的跟随工具；本目录是独立的清怪工具，同一台电脑不要同时运行两套输入控制。

## 下载与启动

1. 仓库点 **Code → Download ZIP** 并完整解压，进入 `farming` 文件夹。
2. 安装 Windows 64 位 Python 3.12（也兼容安装脚本中的 3.11 入口）。
3. 双击 `install.cmd`，在本目录创建 `.venv` 并安装依赖。
4. 双击 `start.cmd`。首次选择本机游戏目录内的 `DNF.exe`，填写本机狂战士角色名。
5. 确认游戏技能栏与下表一致；在助手选择副本、普通级和局数。从根特入口点击“从根特入口进入所选副本并开始”，或已在副本内时点击“开始”。游戏必须保持前台。

默认追击歼灭战普通级、1 局；**局数设为 0 才会持续到疲劳不足**。界面只开放普通级和冒险级。根特东门支持循环；溶岩穴仅单局适配，左门仍有复测限制。

换电脑或改角色名运行 `configure.cmd`。配置只保存在本机，不包含登录账号或密码。客户端 SHA256 不匹配时拒绝套用旧坐标结构；改名不能自动适配其他职业、服务端或不同技能栏。

## 操作规则

| 操作 | 当前配置 |
|---|---|
| 普攻 | X |
| 技能 | Q/W/E/R/T/Y/A/S/D/F/G/H |
| 双刀 | H，启动前用“双刀当前已开”告知初始状态 |
| 血药 | 快捷栏 3：雷米援助；估计 HP 严格低于 30% 才使用 |
| 死亡 | 确认幽灵提示后按 X，最多两次尝试 |
| 无色不足 | 按住 Alt，再按 D 分解 |
| 无色够用 | 按住 Alt，再按 S 卖白装和蓝装 |
| 修理 | 按住 Alt，再按 F |
| 再次挑战 | F10；最后一局维护后不重进 |

无色储备线至少 100，按本局技能输入的保守消耗估计上调。库存读不准时沿用分解分支。出售、分解范围与费用由客户端内置快捷键决定。用户已修正本机快捷键配置并要求继续运行；这不代表其他电脑的快捷键必然相同。

F8 暂停/继续、F9 停止，也可用界面按钮。该客户端中热键曾有冲突，优先使用界面。Enter/Esc 会暂停；手动方向键暂时接管，松开后恢复；切到其他窗口停止输入，回到游戏后继续。关闭助手会释放按键。

## 实际范围与限制

- 根特东门曾连续完成两局，战斗耗时分别 241 秒、188 秒；布局不同，不能保证每局三分钟。
- 追击普通级曾从首房已清空处接回后完成 8 次房间访问，197 秒到结算；包含维护约 266 秒。它不是完整入场计时基准。
- 寻路通过实际移动学习碰撞，没有静态全地图通行数据。仍可能绕路或暂停；未知对象、数据不可靠、重进失败会停止或暂停。
- 清场后等待 3.5 秒并在走向出口时持续检查新怪，处理二轮刷怪。
- 冷却、技能是否施放成功及无色消耗不是精确游戏读数。HP 来自固定 HUD 颜色估计。
- 自动拾取是当前服务器已有功能，本工具未实现拾取。收益仅记录可确认的金币差，不给未出售材料估价，不宣称追击是所有服务器最高收益图。
- Alt+S 历史自动输入曾没有产生卖装效果，用户后来确认手动有效并修改了本机设置，要求停止按键测试。日志中“输入已发送”不能单独当作售卖成功证据。

## 开发与文件

`dungeon_farm/` 包含运行器、GUI、寻路、战斗、库存和结算状态机，以及离线回归用例。可选执行以下命令，仅运行离线用例，不启动游戏输入：

```powershell
.venv\Scripts\python.exe -m unittest discover -s dungeon_farm -p "test_*.py"
```

已有 85 项本机离线回归通过；本次发布按用户要求没有追加游戏按键测试。另一台电脑的游戏行为不由离线结果保证。

运行后会在本机生成 `coordinate-session.json`、GUI 偏好、动作日志、库存读数和异常对象详情。这些数据没有上传；发布包没有游戏客户端、截图、模型训练集、内存转储、登录信息或运行日志。请保留 `.gitignore`。
