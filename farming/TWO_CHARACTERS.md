# 风神与机械之心：自己启动刷图

适用于已核对的本地 70 客户端、阿登高地冒险级和下面这两套技能栏。换技能位置后需要重新配置对应方案。

## 每次启动

1. 登录角色，走到时空海港副本入口附近。
2. 打开刷图助手，点 **读取当前角色**。确认风神对应“风神冷却优先”，机械师对应“机械之心召唤轮换”。
3. 点 **血药、人偶与无色**：选择实际放血药的 1、2 或 3 号键；需要帮手则勾选每局按 4。无色所在的材料栏行列也在这里填写，读取时会核对物品名称。设置按角色独立保存。
4. 选择 **阿登高地、冒险级、局数 0**，保持“自动连续挑战”勾选。
5. 点 **自动入场并开始**，切回游戏。已经在副本内则点普通“开始”。

启动前会核对实际角色名字和类型，选错方案会停止，先读取正确角色再启动。运行中切出游戏会松开按键；切回后继续。F8 暂停/继续，F9 停止。Enter/Esc 会暂停，关掉聊天或菜单后按 F8 恢复。

血药只在血量估计低于 50% 时使用，每局最多一次；暂停和复活不恢复额度。需要自己确认药品没用完，空格可能被自动拾取的材料占用。助手不会购买或补充血药、人偶。

## 两套方案

| 项目 | 风神 | 机械之心 |
|---|---|---|
| 入场增益 | 流风诀：右、下、右、Z；复活后重开 | H 机械改良、F 远古记忆按各自 CD 补充 |
| 人偶 | 开启后每局按一次 4 | 开启后每局按一次 4 |
| 输出 | 短 CD 优先，冷却空档普攻；敌人死后停止伤害技能 | G1/G2/G3 持续维持，G2/G3 变形后补按激活；其他技能穿插普攻 |
| 站位 | 按风神技能范围接近目标 | 优先远程站位，近身受威胁时退避 |
| Boss | 可用输出技能按 CD 调度 | 解除普通房间的节奏限制；确认自己的 G 对象存在后 Y，紧接 C 发动 |

机械师普通房间控制高耗蓝技能，给 Boss 留蓝；不会因为缺蓝额外吃第二瓶药。各技能 CD 来自本机技能面板，实际冷却计时从成功发送按键开始，仍受硬直、动画和网络影响。

## 一局结束后

按无色库存选择 Alt+D 分解或 Alt+S 出售白蓝装备，再 Alt+F 修理，最后 F10 重进。疲劳不足时停止；填写有限局数时，最后一局维护后结束。遇到结算后正常回到海港，按原副本和难度重新入场。

游戏保持前台、角色和快捷栏一致时，这些步骤由助手执行，不需要对话中逐局确认。

## 异常恢复

| 界面状态 | 操作 |
|---|---|
| 游戏角色与方案不符 | 停止，点“读取当前角色”，核对技能方案后重启 |
| 等待游戏／客户端退出或卡死 | 重启客户端并重新登录，到海港入口，再读角色并自动入场；不处理登录账号密码 |
| 暂时找不到通路 | F8 暂停，手动绕开障碍后再 F8；持续失败时保存日志供修复 |
| 城镇进图未完成 | 走到海港入口或手动打开选图，再点自动入场 |
| 血药已用完或换位置 | 停止，在“血药、人偶与无色”改到核实后的药位 |
| 疲劳不足 | 本角色结束；游戏内换角色后重新读取并启动 |

客户端崩溃、登录和持续无法通行的异常仍可能需要人工处理；本版不承诺这些情况下也能全程无人值守。通常刷图循环和故障恢复入口都在本机界面内，使用不依赖助手在线。
