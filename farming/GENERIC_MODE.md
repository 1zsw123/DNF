# 通用模式：手动进图后接管

在助手里选择角色和正确的技能方案，副本选择 **通用模式（手动进图）**，点击开始，再由你单人进入普通清怪副本。已经在副本内也可以开始。难度沿用游戏里的选择，不会自动选图或提高难度。

本机上头狂战使用“狂战士”方案；当前核对到第 3 格为雷米的援助，1、2 格为人偶。换角色或更换快捷栏后，在“血药、人偶与无色”重新核对。狂战的双刀开关仍需与界面勾选一致。

## 通用的部分

- 不按副本名称拦截入场；先确认自己的角色、非城镇场景和真实出口对象。
- 普通怪物按对象类别和当前场景识别，不要求逐个加入旧副本的类型名单；已知人偶、召唤物继续排除。人形 APC 仍只攻击已核对的敌人，未分类对象记录后忽略。
- 战斗期间识别小地图，记住已观察的房间、连接和 Boss 位置。雾区没有连线时不虚构通路，沿真实出口探索，记住已走岔路，死路回退。
- 沿用角色技能、短 CD 优先、普攻、补刷等待、碰撞绕行及门口推进。
- 通关后沿用分解/卖装、修理和 F10 重进。局数 0 为持续运行；疲劳不足停止。回到城镇则等待手动进入下一张图。

## 范围

针对同一个已核验客户端的普通清怪、过门、Boss 副本，不包含机关、护送、对话、特殊破防或组队联动。新地图的非标准出口、未分类人形敌人、不可识别的小地图和复杂地形仍可能需要适配。通用模式不是“所有副本都已实测通过”的保证。

小地图没有完整路线时采用出口探索，可能经过支路。F8 暂停/继续，F9 停止；界面的方向按钮可在清场后指定一个实际存在的出口。发现持续卡路请暂停并保留本机日志。

固定副本方案仍保留，可随时在下拉框切回。公开包不包含本机配置、角色数据、截图、运行日志或内存转储。
