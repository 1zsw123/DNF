# 多角色刷图

## 2026-11-12 风神与机械之心

新增“风神冷却优先”和“机械之心召唤轮换”优先维持 G1/G2/G3：进图召出、按共享冷却切换、变形后补按激活，过门期间续时，意外断档后 Q 冷却结束立即重召。G 核心不受其他技能的间隔限制。H 机械改良每 30 秒、F 远古记忆每 40 秒补一次；4 人偶每局一次，已有杜尔夫时不重复召唤。普通房间保留 G 机器人，觉醒留在 Boss 房使用。

普通房间的其他伤害技能按面板短 CD 优先、同 CD 低 MP 优先，成功发送后留出 2 秒普攻空档（MP 消耗不少于 900 的技能为 3 秒），不要求普攻次数，以免走位或受击导致技能饿死。无敌人时停止普通伤害技能；G 维护和状态技能继续按冷却处理。技能计时基于成功发送输入，不等于已经读到服务器施放确认。

机械师目标站位约距敌人横向 380，普攻估计射程 420、技能估计射程至少 480。进入横向 220、纵向 80 的危险范围时退避。退避横向超过 40 即用跑动，首次进入退避会重新起跑；约 0.18 秒没有移动进展即重新规划，快速判定的阻挡只保留 0.8 秒，不把受击硬直写成永久墙。候选路径考虑沿途敌人距离，保留整房已观察的纵向范围。单次退避最多 1.5 秒并保留短输出窗口。长动作须先拉开安全距离。上述范围是控制器估计，仍须以实战验证。

新角色默认不自动用药。停止后点“血药、人偶与无色”，为当前角色选择已核实的 1、2 或 3 号血药格，界面随角色显示对应按键。只有 HP 估计低于 50% 才吃，每局最多发送一次用药按键，暂停或复活不恢复本局额度，新局重置。死亡按 X 的规则保留。

机械师普通房间为 Boss 预留蓝量：MP 估计不高于 25% 时保留 G、增益和普攻；D/R/T 仅在至少六名敌人且 MP 高于 65% 时加入轮换。未知蓝量不当作零。Boss 房解除普通伤害技能的间隔和上述蓝量限制；觉醒额外要求至少 8% 的蓝量估计。

觉醒前读取已验证的 G2/G3 对象类型、名称及所有者，发送 Y 前再次核对属于本角色。切换后超过短暂生成宽限仍没有实际 G 对象时，撤销虚假的续时状态并重试 Q，避免永久空切换。按用户最新要求，Y 松开后立刻按 C 发动，不等动画计时或下一次坐标采样，两键之间不插入退避或其他技能；失焦或暂停仍会取消尚未发出的输入。已看到实机觉醒立绘；输入日志本身不等同于攻击命中。

阿登高地的血蓝球与小地图一起快速采样，避免等整屏文字识别后资源读数已经过期。蓝量未知时不释放普通房间的 D/R/T；不会因蓝量低而额外使用第二瓶药。

复活重试只依据按 X 后重新采集的画面，旧死亡画面不会触发第二次 X 或“复活失败”。若 20 秒仍无新的有效画面，会报告未能确认并停止，避免对丢失画面的客户端持续输入。

个人配置不随公开源码发布。推荐在界面“血药、人偶与无色”中开启每局按 4。也可关闭助手后，在本机 `dungeon_farm/characters.json` 找到已读取的目标角色，仅更新以下字段，保留已有名字、角色类型和其他字段，然后重开助手：

```json
{
  "rotation": "刃影冷却优先",
  "auto_potion": true,
  "potion_key": "1",
  "entry_helper": true
}
```

以上是字段示例，不可覆盖整个配置文件。确认 1 为血药、4 为人偶后启用；不需要帮手时将 `entry_helper` 设为 `false`。每局先按一次 4，再开追踪术；换小房间、暂停恢复和复活不重复按 4。2、3 虽也可能放药，未确认用途的按键不会加入轮换。

阿登高地机械师进入小地图已确认并记住的 Boss 房后，取消其他伤害技能的额外间隔和普攻配额，所有可用输出技能按冷却释放，觉醒不再等待 G1 接近重新召唤时间。仍遵守施法动画锁、目标存活、远程距离和长动作安全距离；技能全在冷却时使用 X。离开 Boss 房后恢复普通房间的节奏。

机械师退避时给敌人周围添加临时寻路代价，优先绕过其近身和直线攻击区域；这些区域不会写成地形墙。整间房已经观察到的纵向活动范围会保留，小怪减少后不缩窄。优先在已观察范围内侧移；若真实障碍封住该范围，允许原寻路继续探索绕行，保留已确认的墙体。过门和其他职业仍用原有地形寻路。

## 新地图

按用户当前选择，单人刷图及大号清怪模式遇到未适配对象只记录并忽略，不停止、不把它加入攻击目标。已识别怪物继续正常处理；清场仍经过原有二轮刷怪等待及路线确认。若未知对象实际是必须击杀的敌人，忽略不会替代击杀，游戏可能仍不允许过门。小号跟随的清场判定保持独立。

已有阿登高地冒险级通关和连续重进的实机观测。已处理场外停放的门对象和北侧门复用“下侧门”名称的问题。单人及清怪大号按用户设置记录并忽略未适配对象；小号跟随仍单独确认清场。双机整合仍需真实双机验收，见[双机组队说明](双机组队使用说明.md)。

寻路遇到短时四面封闭时，先松键 0.75 秒，最多两次重新验证附近 4 秒内推测出的障碍，保留较早和远处的障碍记录。角色重新移动超过 60 像素后恢复重试次数；真实持续卡死仍暂停，避免无限原地打转。这用于处理动画或受击期间不动造成的误判，并不表示已从客户端读到硬直状态。

施法或暂停会重置连续移动的停滞计时，保留已学习的地形；分散在多次战斗中的后撤不再累计成同一次寻路失败。

阿登高地进图即建立到 Boss 的房间图，战斗中提前规划出口，整局记忆并按实际过门推进；短暂小地图漏检保留已有路线。门旁增加避免误回入口和停滞后重新对齐的处理。校准针对当前客户端的 4×5 小地图，不代表所有地下城通用。

可从时空海港入口附近点击“自动入场并开始”，已验证向右进入选图并选择阿登高地冒险级。其他城镇位置请手动打开选图界面或先进入副本。点击普通“开始”后若仍在城镇，助手等待进图，进入正确副本和难度后自动接管。

海港入口连续右移不动时，按已核对的本地城镇坐标尝试有限的上下对齐，再右移；总步数仍受限，不能从任意城镇位置导航入场。

单人循环发送 F10 后，如果同时读到海港标题、城镇场景和正确角色，会按原副本、原难度重新入场，保留已完成局数。疲劳不足仍停止；双机模式不使用此回城恢复。

本客户端进图标题为“决战的都市－亚顿”，已映射到选图界面的“阿登高地”。长标题末尾的难度可能被截掉：手动入场且地图、角色和门对象都核对成功时，沿用界面选择的难度；若读到明确不同的难度则停止。脚本自己选择地图入场时仍须核对选图难度。F10 重进保留原难度，且必须出现新的有效场景。

可选普通、冒险、勇士，脚本不会自动升难度。首局默认 1 局；需要循环时将局数设为 0。后续仍按无色库存选择 Alt+D 分解或 Alt+S 出售白蓝装备，再 Alt+F 修理、F10 重进。

离线检查覆盖角色隔离、全技能轮换、错误角色配置、地图标题别名和阿登门方向。一次实机通关不代表所有布局均已验证。角色配置、场景对象记录和游戏日志只留本机。
