# 多角色刷图

下载仓库后进入 `farming`，先运行 `install.cmd`，再运行 `start.cmd`。界面选择本机角色、副本、难度及局数；默认 1 局，设为 0 才连续刷到疲劳不足。

## 换角色

在游戏里登录目标角色，停止刷图后点击“读取当前角色”。程序读取当前角色的名字和类型，保存到本机 `dungeon_farm/characters.json`，以后可直接从角色下拉框选择。选择的是脚本控制对象，不会自动登录账号或替你切换游戏角色；角色不一致时不会启动攻击。

每个角色分别保存技能方案、血药键和是否允许自动用药。狂战士专用 H 双刀开关、Y 两段觉醒仅在选择“狂战士”方案时生效。“通用全技能”轮换 Q/W/E/R/T/Y/A/S/D/F/G/H 并使用 X 普攻，间隔是调度估计，不读取真实冷却，也不保证适合所有职业的蓄力、开关和召唤机制。

“刃影冷却优先”使用已核对的技能面板 CD，短 CD 优先、同 CD 低 MP 优先，攻击前再次核对目标；冷却空档用 X。每局用右、右、空格施放追踪术，复活后重开。快捷栏须与[刃影技能说明](刃影技能说明.md)一致。

新角色默认不自动用药。上头影刃已按用户确认设为快捷栏 1 血药并开启，原狂战士仍使用快捷栏 3；界面随角色显示对应按键。只有 HP 估计低于 50% 才吃，每次至少间隔 10.5 秒。死亡按 X 的规则保留。

个人配置不随公开源码发布。帮手目前通过角色配置开启，界面尚无独立勾选项。关闭助手后，在本机 `dungeon_farm/characters.json` 找到已读取的目标角色，仅更新以下字段，保留已有名字、角色类型和其他字段，然后重开助手：

```json
{
  "rotation": "刃影冷却优先",
  "auto_potion": true,
  "potion_key": "1",
  "entry_helper": true
}
```

以上是字段示例，不可覆盖整个配置文件。确认 1 为血药、4 为人偶后启用；不需要帮手时将 `entry_helper` 设为 `false`。每局先按一次 4，再开追踪术；换小房间、暂停恢复和复活不重复按 4。2、3 虽也可能放药，未确认用途的按键不会加入轮换。

## 新地图

已有阿登高地冒险级通关和连续重进的实机观测。已处理场外停放的门对象和北侧门复用“下侧门”名称的问题。其他布局或未知对象仍可能停止，不能将未适配对象当成清场。双机整合仍需真实双机验收，见[双机组队说明](双机组队使用说明.md)。

阿登高地进图即建立到 Boss 的房间图，战斗中提前规划出口，整局记忆并按实际过门推进；短暂小地图漏检保留已有路线。门旁增加避免误回入口和停滞后重新对齐的处理。校准针对当前客户端的 4×5 小地图，不代表所有地下城通用。

可从时空海港入口附近点击“自动入场并开始”，已验证向右进入选图并选择阿登高地冒险级。其他城镇位置请手动打开选图界面或先进入副本。点击普通“开始”后若仍在城镇，助手等待进图，进入正确副本和难度后自动接管。

本客户端进图标题为“决战的都市－亚顿”，已映射到选图界面的“阿登高地”。长标题末尾的难度可能被截掉：手动入场且地图、角色和门对象都核对成功时，沿用界面选择的难度；若读到明确不同的难度则停止。脚本自己选择地图入场时仍须核对选图难度。F10 重进保留原难度，且必须出现新的有效场景。

可选普通、冒险、勇士，脚本不会自动升难度。首局默认 1 局；需要循环时将局数设为 0。后续仍按无色库存选择 Alt+D 分解或 Alt+S 出售白蓝装备，再 Alt+F 修理、F10 重进。

离线检查覆盖角色隔离、全技能轮换、错误角色配置、地图标题别名和阿登门方向。一次实机通关不代表所有布局均已验证。角色配置、场景对象记录和游戏日志只留本机。
