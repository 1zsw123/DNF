# 刃影冷却优先

此方案按当前客户端、上头影刃的已学习技能面板核对，快捷栏未移动。

本机角色配置 `entry_helper: true` 时，每局进图先按一次 4 召唤帮手，再开追踪术。过小房间、暂停恢复和复活均不重复按 4；下一局重新召唤。输入失败可重试，已发送后不会因未看到帮手而连续消耗道具。

进图先用“右、右、空格”施放追踪术 Lv10，每局一次，复活后重新启用。面板显示冷却 5 秒、MP 528 + 每秒 44；它不会按 5 秒间隔重复释放。该增益有持续耗蓝，不能把总耗蓝都归因于攻击技能。

可用技能按短 CD 优先，同 CD 按低 MP 优先；目标不在技能范围时先靠近。技能冷却中用 X 普攻衔接。每次按键前再次读取当前目标，目标死亡、消失、换房或离开攻击范围就取消，不执行预排长串连招。

冷却以面板秒数和成功发送的按键时间计时，跨房、跨连续局保留；没有直接读取服务器冷却，也不能仅凭发送成功证明服务器已施放。动作锁定时间和攻击范围仍为控制器估计。更换装备导致 CD 变化、调整快捷栏或角色技能后需要重新核对此方案。
